# TokenPanel v0.1.7 — 应用图标

这次是外观与交付形态的更新，统计逻辑没有变化。

## 应用图标

新增一套真正的应用图标：暖深色圆角底板、三段递增的橙色柱，呼应面板里的用量图表。

- 内嵌 **10 档尺寸**（16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256 px），任务栏、桌面、文件属性里都清晰
- 按 4096px 超采样绘制后降采样，16px 下三根柱子依然可分辨
- 浅色与深色任务栏都做过对比测试，边缘有极细描边保证轮廓
- 官网与面板页面同步使用该图标作为 favicon

## 桌面便携包

解压后是一个文件夹，包含：

| 文件 | 用途 |
|---|---|
| `TokenPanel.exe` | 主程序，双击即用 |
| `使用说明.txt` | 三步上手 + 遇到弹窗怎么办 |
| `SHA256SUMS.txt` | 官方校验值 |
| `verify.bat` | 双击自动比对哈希 |

数据保存在同目录 `data\`，整个文件夹可以拷到 U 盘带走。

## 升级说明

直接覆盖旧版 `TokenPanel.exe` 即可，历史数据不用重扫。启动时会自动把新价格表里缺的型号补进你的 `pricing.json`，已有的自定义价格不会被覆盖。

## 已知边界

- exe 仍未做代码签名（公开渠道已无可用的免费可信证书）。首次运行可能提示「Windows 已保护你的电脑」，核对 `SHA256SUMS.txt` 后点「更多信息 → 仍要运行」。详见 [签名说明](https://github.com/hhxpoint/tokenpanel/blob/main/docs/signing.md)
- 8 条 Qoder 记录没有模型名，无法计价
- Cursor / Trae / Copilot / CodeBuddy / Marvis 本地日志不含 token 字段，仅标注为「已发现」

## 校验值

以本 Release 附带的 `SHA256SUMS.txt` 为准。
