# TokenPanel v0.1.4

**下载 `TokenPanel.exe`，双击即用。**

## 这是一个数据准确性修复

### 凌晨的用量不再被算到前一天

之前按天统计用的是 UTC 日期。对北京时间来说，**每天 00:00–08:00 的调用会被归到前一天**。

实测本机数据里，仅 3 月就有 198 条记录被错分到别的日期：

| UTC 日期 | 实际本地日期 | 受影响记录 |
|---|---|---|
| 03-24 | 03-25 | 60 条 |
| 03-22 | 03-23 | 107 条 |
| 03-20 | 03-21 | 31 条 |

现在全部按本地时区分组，柱状图、热力图的每一天都对应你真实的作息。

### 自检 47 项

新增「时区归日」两组断言：本地 00:30 和 23:30 的事件都必须落在当天。这条测试在 UTC 时区的 CI 机器上同样成立。

## 怎么用

1. 把 `TokenPanel.exe` 放到任意有写权限的文件夹
2. 双击
3. 秒开界面，十几秒后数据补齐

> **首次运行 Windows 可能提示「Windows 已保护你的电脑」**
> 未做代码签名（个人项目无证书），点「更多信息」→「仍要运行」即可。

## 升级方式

直接下载覆盖即可。数据在 `data\tokenpanel.db`，不受影响；已采集的历史记录无需重新扫描。

## 隐私

只读本地日志与 SQLite（`mode=ro`）。唯一联网行为是你主动点击「检查更新」时的一次版本查询。

## 已知边界

- **仅 Windows 10/11 x64**；macOS / Linux 请从源码运行
- **Qoder** 仅部分会话含 usage 字段
- **Cursor / Trae / Windsurf / Copilot** 用量在云端，本地无逐次记录
- **未定价模型** 金额显示为「—」，在 `pricing.json` 补单价后重新扫描即可
