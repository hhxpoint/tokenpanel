# TokenPanel v0.1.9 — 模型价格总览与技术动态

新增两个栏目，把「花了多少钱」补上参照系：一个是全量模型价格表，一个是各家官方博客。

## 新增栏目：模型价格

顶部导航分成「概览 / 模型价格 / 技术动态」，价格页把所有平台放在一起对比。

| 列 | 说明 |
|---|---|
| 平台 | 带品牌色圆点，可按平台筛选 |
| 模型 | 显示展示名 + 实际 model id |
| 上下文 | 官网标注的上下文窗口 |
| 输入 / 输出 / 缓存命中 | 每百万 tokens 单价，保留原币种（¥ / $） |
| 状态 | **已核实**（本次直接读取官网）/ **待核对** |
| 来源 | 直达官网定价页 |

支持按平台筛选、按币种筛选、关键字搜索。

## 修正：DeepSeek 价格此前是错的

对照官网后发现旧值有明显偏差：

| 项 | 旧值 | 官网 |
|---|---|---|
| 缓存命中 | $0.028 | **$0.006** |
| 输出 | $0.42 | **$1.20**（峰时） |
| 输入 | $0.28 | **$0.30**（峰时） |

缓存价高估了近 5 倍，而 dsh 的用量里 99% 是缓存读。修正后全库成本从 **$75.06 降为 $43.12**。

## 新增栏目：技术动态

聚合各家官方博客的 RSS，不爬第三方转载：

- OpenAI（1422 篇）
- Qwen（44 篇）
- NVIDIA（18 篇）
- BAIR（10 篇）

每个源取最新 18 篇后再合并，避免 OpenAI 这种大 feed 把其他来源挤掉。支持按来源筛选，点卡片直达原文。

**离线可用**：抓取结果缓存在本地，断网时照常展示，并显示「上次抓取」时间。只有点「抓取最新」才会联网。

## 工程细节

- 价格表 `catalog.json` 随 exe 打包，升级时若内置版本更新则自动覆盖
- 博客缓存落在 `data/blogs.json`，半小时内不重复抓取
- 前端只用标准库渲染，无新增第三方依赖
- 支持 `#prices` / `#blogs` 深链接

## 验证

- 自检 **60 项全通过**，新增价格结构/检索/核实状态传递、RSS 与 Atom 解析、离线降级、两个新接口
- 实测接口：22 个型号、13 个已核实、60 条动态
- 抓取耗时：OpenAI 1.6s、Qwen 4.6s、NVIDIA 1.2s、BAIR 10s（并行执行）

## 升级

直接覆盖旧版 `TokenPanel.exe`。价格表会自动同步，`data/` 历史数据保留。
