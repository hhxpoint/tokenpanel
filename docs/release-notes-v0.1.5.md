# TokenPanel v0.1.5

**下载 `TokenPanel.exe`，双击即用。**

## 这版新增

### 图例可以点了

趋势图下方的客户端图例现在能点击，用来隐藏/显示某个来源。同时用着好几个客户端、柱子太挤的时候，点掉不关心的那个就行。选择会记在本地，下次打开还是你上次的样子。

### 会话表能排序

点「调用 / Token / 成本 / 最近活动」这几个表头可以排序，再点一次切换升降序。找"哪次会话最烧钱"不用再肉眼扫。

### 看到环比

总 Token 和总成本现在显示与上一周期的对比：`2,556 次调用 · 较上期 ↑136.1%`。

- 用量上升标红，下降标绿
- 选「全部时间」时不显示（没有可比的上期）

### 修了一个误导性提示

之前界面渲染出错会显示「无法连接本地服务」，让人以为是网络问题。现在会区分：网络故障说连接问题，渲染异常说界面出错，方便排查。

## 顺手补的文档

- 新增 `CHANGELOG.md`，从 v0.1.0 到现在的全部变更都在里面

## 怎么用

1. 把 `TokenPanel.exe` 放到任意有写权限的文件夹
2. 双击
3. 秒开界面，十几秒后数据补齐

> **首次运行 Windows 可能提示「Windows 已保护你的电脑」**
> 未做代码签名（个人项目无证书），点「更多信息」→「仍要运行」即可。

## 升级方式

直接覆盖 exe。数据在 `data\tokenpanel.db`，历史记录不用重扫。

## 已知边界

- **仅 Windows 10/11 x64**；macOS / Linux 请从源码运行
- **Qoder** 仅部分会话含 usage 字段
- **Cursor / Trae / Windsurf / Copilot** 用量在云端，本地无逐次记录
- **未定价模型** 金额显示为「—」，在 `pricing.json` 补单价后重新扫描即可
