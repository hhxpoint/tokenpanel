# TokenPanel v0.2.0 — 双币种与实时汇率

价格页现在同时显示人民币和美元，换算用的汇率来自公开接口，并带完整降级策略。

## 双币种对照

每个单价下方多一行灰色小字，显示另一种货币的参考值：

```
输入          输出         缓存命中
$0.3          $1.2         $0.006
≈ ¥2          ≈ ¥8.02      ≈ ¥0.04
```

- 美元计价的平台（DeepSeek、Claude、OpenAI）小字显示人民币
- 人民币计价的平台（智谱、千问）小字显示美元
- 总成本卡也加了：`$43.12 · 10,587 次调用 · ≈ ¥288.09`

## 汇率来源与可靠性

用两个公开源，按顺序尝试：

| 顺序 | 来源 | 类型 |
|---|---|---|
| 1 | open.er-api.com | 市场价，每日更新 |
| 2 | ECB / frankfurter.app | 欧洲央行参考价 |

面板底部会写清楚：**汇率数值 · 来源 · 更新时间**，旁边有「刷新汇率」。

### 五层防护

1. **区间校验**：汇率必须落在 5–9 之间，超出视为脏数据直接丢弃
2. **缓存 6 小时**：不会每次打开都请求，也不会拿到十几次不同的数
3. **双源回退**：主源挂了自动换 ECB
4. **断网降级**：沿用上次缓存，并标注「本次未联网，沿用上次」
5. **最终兜底**：连缓存都没有才用内置 7.0，并标注「内置参考值」

另有 `TP_USD_CNY=7.25` 环境变量可强制指定，便于对账。
