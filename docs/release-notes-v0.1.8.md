# TokenPanel v0.1.8 — 扫描过程看得见，活跃度看整年

这一版解决两个体验问题：扫描时只有一个转圈、不知道在干什么；活跃度只看得到 90 天。

## 扫描过程可视化

以前扫描时只有一句「正在扫描本机数据」，没有任何细节，一等等十几秒会让人怀疑卡住了。现在把整个过程摊开：

```
◜ 正在扫描本机数据   正在读取 dsh    2/6          4.9s   隐藏
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[✓ Claude Code 2 文件·15 条] [● dsh 读取中] [○ Codex 等待] [○ OpenCode 等待] …
计划扫描 6 个数据源
Claude Code：2 个文件 · 解析 15 条 · 新增 0 条 · 25 ms
```

具体能看到：

- **当前在读哪个客户端**，以及它已经读了多少文件
- **已完成 / 总数据源**，进度条按完成数推进
- **实时耗时**，每 100ms 刷新，不是每次请求才跳一下
- **每个数据源的状态**：等待 / 读取中 / 完成 / 跳过，用颜色和圆点区分
- **滚动日志**：每个数据源的文件数、解析条数、新增条数、耗时

结束后显示「扫描完成 · 新增 N 条」并自动收起，同时刷新图表。

### 顺手修掉的三个隐患

1. **超时自愈**：扫描线程若异常退出，状态会永远停在「扫描中」。现在 300 秒未完成会自动复位并给出提示。
2. **重复点击**：连点「重新扫描」，第二次立即返回「已有扫描在进行中」，不再排队十几秒没反应。
3. **点了没反馈**：请求是同步的，以前要等它返回才有动静。现在点击瞬间就把进度面板亮起来。

## 活跃度改为近 365 天

- 53 列 × 7 行的一年视图，按周排列，首日自动对齐到正确的星期
- 顶部有月份标签，左侧有一 / 三 / 五 星期标签
- 格子尺寸随卡片宽度自适应，窄屏自动缩小，不会撑破布局
- 悬停显示「日期 · 当天消耗」
- 统计升级为四项：活跃天数（/365）、日均（活跃日）、单日峰值、最长连续

热力图改用独立接口 `/api/heatmap`，与右上角的时间范围解耦——切到「近 7 天」时，热力图仍然完整显示一整年。

## 验证

- 自检 **52 项全通过**，新增扫描进度流转、超时自愈、一年热力图接口断言
- exe 实测：界面 0.13 秒就绪，扫描 4.8 秒完成，进度按 1/6 → 6/6 正常推进
- 热力图接口返回 365 天、41 个活跃日、峰值 3.72 亿

直接覆盖旧版 `TokenPanel.exe`，历史数据不用重扫。
