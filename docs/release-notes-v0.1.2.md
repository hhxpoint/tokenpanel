# TokenPanel v0.1.2

**下载 `TokenPanel.exe`，双击即用。** 不需要 Python、不需要命令行。

## 这版改了什么

### 能检查更新了

页脚显示当前版本号，旁边有「检查更新」。点一下才会联网查询最新版本——**平时不做任何网络请求**，断网时会直接提示"无法检查更新"，不会报错也不会卡住。

有新版本时按钮会变成「有新版本 vX.Y.Z」，再点一次跳转到下载页。

### 导出的安全边界

之前导出没有上限。现在如果记录超过 20 万条会明确提示「请缩小时间范围」，而不是悄悄给你一个残缺的 CSV 或把内存吃满。

### 脏数据不再污染统计

从日志里读到的 token 值如果异常（负数、非数字、大到不可能），会收敛到合理范围，不会让某一天的柱状图飙到天际。

### 端口被占用时给建议

以前端口冲突只抛个异常堆栈。现在会直接告诉你「可能已有实例在运行，如需换端口用 `--port 8766`」。

### 自检 36 项

新增 4 项：版本号比较、断网降级、脏数据收敛、导出超限。

## 怎么用

1. 把 `TokenPanel.exe` 放到任意文件夹
2. 双击
3. 秒开界面，十几秒后数据补齐

> **首次运行 Windows 可能提示「Windows 已保护你的电脑」**
> 这是未做代码签名（个人项目无证书）导致的，不是文件有问题。
> 点「更多信息」→「仍要运行」即可。

## 隐私

只读本地日志与 SQLite（`mode=ro`）。唯一的联网行为是**你主动点击「检查更新」**时的一次版本查询，不上传任何数据。

## 已知边界

- **仅 Windows 10/11 x64**；macOS / Linux 请从源码运行
- **Qoder** 仅部分会话含 usage 字段
- **Cursor / Trae / Windsurf / Copilot** 用量在云端，本地无逐次记录，面板会标注「仅发现」而不是估算
- **未定价模型** 金额显示为「—」，在 `pricing.json` 补单价后点「重新扫描」即可
