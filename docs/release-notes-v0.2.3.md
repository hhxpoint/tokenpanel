# TokenPanel v0.2.3 — 光标微光

这次只改一件事：把光标特效从「一大团光晕」重做成「看得见的细节」。

## 改了什么

**删掉 520px 的柔光晕。** 原来那个跟随指针的暖色圆形渐变，铺开半径 260px、带 18px 模糊，落在浅色背景上难免糊成一片。现在整块移除。

**换成沿轨迹逸散的细粒子。** 指针每移动约 4.6px 投放 1 颗，每颗直径 0.7–1.9px，暖橙到琥珀之间随机取色，带 2.8px 微光；寿命 680–1300ms，期间向上飘、速度递减、按 `life^1.7` 淡出，还叠了一层周期 0.021rad/ms 的呼吸闪烁（±16%）。高速划过自然加密，静止后自行消散。

**光标处只留一枚通透的细环。** 半径 9.5px，1px 外环（不透明度 34%）+ 0.62 倍半径的内环（13%）+ 1.35px 光核。整环按 2.2s 周期轻微起伏 ±5.5%，悬停在按钮、链接、输入框、卡片上时放大到 1.5 倍。没有实心填充，落在白底上仍是白底。

**点击时扩散一圈细描边涟漪。** 半径 5→47px，线宽与不透明度同步衰减，最多同时 5 圈。

**卡片高光改为局部发生。** 光标在哪张卡里，哪张卡才浮现 190px 的极淡暖光（峰值 7.5%），离开即淡出。不再全屏铺光。

## 性能与无障碍

- 全部特效收敛到一个 `canvas` + 一个 `requestAnimationFrame`，静止 700ms 后自动停机，不占帧
- 粒子总量上限 160，超出按 FIFO 淘汰
- 高 DPR 屏按 `devicePixelRatio`（上限 2）缩放，线条不发虚
- `prefers-reduced-motion: reduce` 与触屏设备整体关闭
- 画布 `z-index:45`，低于顶栏与提示层，`pointer-events:none` 不影响任何交互

## 验证

- 内建自检 71 项全过
- 用 Chrome DevTools Protocol 派发真实鼠标轨迹，截图核对：光环为 1px 细线、环内保持白底、轨迹上可见离散光点、无大面积橙色雾状区域
- 控制台无报错，`#fx` 画布有非透明像素但总量极低（约 1.3k 个，含抗锯齿边缘）
