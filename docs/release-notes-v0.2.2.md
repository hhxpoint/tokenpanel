# TokenPanel v0.2.2 — 消除空白，加入呼吸感

这一版只改视觉与手感，统计逻辑没有变化。

## 空白是怎么来的

右侧「WorkBuddy 计费快照」有 5 条会话，比左侧热力图高出一百多像素。两栏用 `align-items:start` 对齐时，左侧卡片不会拉伸，于是下面留出一块纯背景色的空洞。

修法不是把卡片压扁，而是**用有用的内容填满**：

- 新增「星期分布」——把一年的消耗按周一到周日聚合，7 根柱子，最高的一天用深色高亮
- 两栏改为等高，分布图贴底，卡片底部齐平

同一行的「模型用量 / 项目用量」也有类似错位，项目卡补了一行合计并贴底：

```
前 10 个项目                    23.04亿 tokens · 占 99.7%
```

> 顺带修了一个数据错误：这个百分比最初恒显示 100%，因为接口只返回前 10 个项目，分母算成了自己。

## 动效

| 效果 | 说明 |
|---|---|
| **光标光晕** | 520px 暖色柔光跟随指针，0.12 的缓动系数形成尾随感，不抢内容 |
| **品牌呼吸** | 左上角标记以 6.5 秒周期轻柔扩散光晕 |
| **入场过渡** | 卡片自下而上浮入，附带 3px 模糊消散 |
| **柱状生长** | 星期分布从底部生长，7 根依次错开 40ms |
| **卡片悬停** | 上浮 + 暖色描边 + 柔和投影 |

### 全部可关闭

系统开启「减少动效」时：光晕不初始化、所有动画降为瞬时、保留最终状态。触屏设备（`hover: none`）同样不启用光晕。

## 无障碍

- 补了 `:focus-visible` 键盘焦点样式，颜色与品牌主色一致
- 页面滚动改为平滑，但同样受「减少动效」控制

## 验证

- 自检 71 项全通过
- 1440 宽下逐块截图核对：热力图行、模型/项目行底部均齐平，无残留空洞
- 光晕用模拟指针事件截图确认位置与强度，文字可读性未受影响

直接覆盖旧版 `TokenPanel.exe`。
