# TokenPanel v0.1.1

**下载 `TokenPanel.exe`，双击即用。** 不需要 Python、不需要命令行。

## 这版改了什么

### 打开更快

之前双击后要等 10 秒（先扫描完才开窗口，期间毫无反馈）。现在**先开窗口显示骨架屏，扫描在后台跑**，实测 0.7 秒就能看到界面，扫描完成后自动刷新出数据。

### 关窗口就退出

之前关掉窗口，后台进程还在跑、占着端口，任务管理器里能看到残留。现在页面会定时发心跳，窗口关闭 3 分钟后进程自动退出，不留僵尸。

### 能导出报表

右上角新增「导出」按钮，把当前时间范围内的逐条明细导出成 CSV，UTF-8 BOM 编码，Excel 双击打开不乱码。

字段：时间、客户端、会话、项目、模型、输入、输出、缓存读、缓存写、推理、成本。

### 其他

- 并发双击不会再起两个实例
- 扫描过程中界面顶部有明确提示，不再是空白页
- 自检从 28 项扩展到 32 项（新增心跳与扫描状态）

## 怎么用

1. 把 `TokenPanel.exe` 放到任意文件夹
2. 双击
3. 秒开界面，5–15 秒后数据补齐

> **首次运行 Windows 可能提示「Windows 已保护你的电脑」**
> 这是未做代码签名（个人项目无证书）导致的，不是文件有问题。
> 点「更多信息」→「仍要运行」即可。

数据保存在 exe 同目录的 `data\tokenpanel.db`，连同 `pricing.json` 一起拷走就是完整便携部署。

## 隐私

只读本地日志与 SQLite（`mode=ro`），不发任何网络请求。

## 已知边界

- **仅 Windows 10/11 x64**；macOS / Linux 请从源码运行
- **Qoder** 仅部分会话含 usage 字段
- **Cursor / Trae / Windsurf / Copilot** 用量在云端，本地无逐次记录，面板会标注「仅发现」而不是估算
- **未定价模型** 金额显示为「—」，在 `pricing.json` 补单价后点「重新扫描」即可
